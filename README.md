## Deployment

1. Create a GitHub repository named `namaste-cabs`.
2. Upload all files and folders.
3. Open repository Settings.
4. Select Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose the `main` branch and `/ (root)`.
7. Save.
8. Enter `namastecabs.co.in` in Custom domain.
9. Configure the domain DNS records with your domain provider.
10. Enable HTTPS after DNS verification.

## Booking

Online booking enquiries use FormSubmit.
The first submission requires email verification.

WhatsApp booking opens a pre-filled WhatsApp message.

## Important

GitHub Pages does not provide a database or backend.
Bookings are enquiries until manually confirmed.
